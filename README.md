# 学习通AI答题小助手（Region改良款）

> 由 [ScriptCat #711《🥇超星学习通｜知到智慧树——网课小助手》](https://scriptcat.org/zh-CN/script-show-page/711)（原版 v0.2.7）改良而来，在此向原作者致敬。

本脚本是一款运行在**超星学习通**网页上的用户脚本（Userscript），最大特色是**接入任意 OpenAI 兼容 AI 接口**来完成答题，不再依赖任何第三方题库。

---

## ✨ 特性

- **AI 答题**：对接任意 OpenAI 兼容格式的 AI 接口（OpenAI / DeepSeek / 通义千问 / 本地 Ollama 等）。在脚本面板「答题」设置中填写接口地址、API Key、模型即可自动作答。
- **全题型支持**：单选、多选、判断、填空、简答，脚本会把题干与选项发给你的 AI，并解析回复后自动填入。
- **覆盖主要学习场景**：视频播放、章节测试、作业与考试自动完成。
- **专注超星学习通**：已移除原版的知到智慧树（zhihuishu）相关代码，仅保留并专注于超星学习通。
- **无题库依赖**：移除了第三方题库与题库密钥，答题完全由你自己的 AI 完成。
- **轻量纯净**：移除了原版的远程公告 / 版本更新功能。

---

## 📦 安装

1. 安装一个用户脚本管理器（任选其一）：
   - [Tampermonkey](https://www.tampermonkey.net/)
   - [ScriptCat](https://scriptcat.org/)
   - 暴力猴（Violentmonkey）等支持 `@require` / `@connect` 的管理器
2. 将本仓库的 `网课小助手-AI答题版.user.js` 文件拖入管理器，或复制其内容新建脚本保存。
3. 确认脚本已启用。

---

## ⚙️ 配置（必做）

安装后**必须配置 AI 接口**脚本才会答题：

1. 打开超星学习通任意页面，点击脚本管理器图标打开本脚本的**面板**。
2. 切到 **「答题」** 标签页。
3. 勾选 **启用 AI 接口答题**。
4. 填写以下信息：
   | 配置项 | 说明 | 示例 |
   | --- | --- | --- |
   | 接口地址 (baseUrl) | OpenAI 兼容的 `/v1` 基址 | `https://api.openai.com/v1`、`https://api.deepseek.com/v1`、`http://localhost:11434/v1` |
   | API Key | 你的接口密钥 | `sk-xxxx` |
   | 模型 (model) | 调用的模型名 | `gpt-4o-mini`、`deepseek-chat` |
   | 温度 (temperature) | 可选，默认 0.2 | `0.2` |
   | 自定义提示词 | 可选，追加给 AI 的额外要求 | `只用中文回答` |
5. 刷新页面后即可在视频、章节测试、作业、考试页面自动调用 AI 作答。

> 配置会随脚本配置自动保存，下次打开无需重复填写。
