## v1.26 — 修复「切换标签内容变了但高亮不动」
- 现象：点「协议」内容已切换，但 `.active` 高亮仍停在「首页」。
- 根因：手写编译式渲染里标签按钮 `patchFlag=9`(TEXT|PROPS) 且 `dynamicProps=["onClick"]`，**缺 CLASS 位** → Vue `patchElement` 更新时只按 dynamicProps 补 onClick，不重算 class。
- 修：标签按钮 patchFlag 改 `10`(CLASS|PROPS)；日志条目 class 同样 10。
- 验证：jsdom 依次点 协议/设置/答题/首页，active 逐一跟随，0 报错。
- 教训（写编译式 render 必看）：只要 `class`/`style` 会随状态变化，patchFlag 必须带 CLASS(2)/STYLE(4) 位，或干脆不给 patchFlag 走全量 diff；否则复用节点时 class/style 不更新。
- 已 commit `6340f0d`，push main + tag `v1.26`。
