学习通AI答题小助手（Region改良款）

运行在超星学习通网页上的用户脚本。最大特色是接入任意 OpenAI 兼容的 AI 接口来完成答题， 不依赖任何第三方题库；同时保留视频自动播放、文档自动阅读、章节测试 / 作业 / 考试自动完成等能力。

安装脚本（最新版） GitHub 仓库

项目简介

从 ScriptCat #711 改良而来，专注超星学习通 + 自有 AI 接口。

本项目基于 ScriptCat #711《超星学习通｜知到智慧树——网课小助手》（原版 v0.2.7）改良， 在此向原作者致敬。改良款做了三件核心的事：砍掉第三方题库、只保留超星学习通、把答题能力交给你自己的 AI。

脚本在页面加载时只创建一个极轻量的悬浮按钮，点击后才挂载面板，因此不会拖慢超星页面； 面板内部已完全不依赖 ElementPlus，全部使用原生组件实现，打开与点击都不再卡顿。

OpenAI 兼容接口 无题库依赖 原生面板 · 不卡顿 GitHub Pages 自动更新

核心特性

功能按「答题 / 学习流程 / 面板 / 更新」四类整理。

AI 自动答题

对接任意 OpenAI 兼容接口（OpenAI、DeepSeek、通义千问、豆包、Kimi、小米 MiMo、本地 Ollama 等），把题干与选项发给你的 AI，解析回复后自动填入。

全题型支持

单选、多选、判断、填空、简答均可处理，不依赖任何题库与题库密钥。

预设接口源 + 一键测试

「答题」页内置预设下拉，选中即填好接口地址；点「测试连接」用极简 ping 请求验证地址 / 密钥 / 模型是否可用，并显示失败原因。

视频自动播放与切换

自动定位任务点视频（含多层 iframe 兜底查找）并播放，看完自动进入下一章节。

文档 / PPT 自动阅读

递归进入嵌套 iframe，滑动到真正的内容渲染层，自动完成文档、PDF 的阅读任务点。

视频智能加速

自动选取播放器允许的最高倍速（默认 2x，课程开放更高则取更高）；支持拖到结尾前几秒快速完成，教师禁止拖动时回退高倍速播放。

覆盖主要场景

视频任务点、章节测试、作业、考试均可自动完成；支持自动提交与正确率阈值策略。

运行日志与导出

「首页」实时显示运行日志，可滚动查看，并支持一键导出为 .txt，方便排查问题。

轻量原生面板

面板已移除 ElementPlus，全部原生实现；页面加载只创建一个悬浮按钮，点击才挂载，打开不卡、点击不卡。

自动检查更新

更新地址使用 GitHub Pages（约 10 分钟缓存），发布新版本后很快就能收到更新提示。

安装

三步完成，只需装一次。

安装用户脚本管理器

任选其一：Tampermonkey（油猴）、ScriptCat、暴力猴（Violentmonkey）等支持 @require / @connect 的管理器。

打开脚本地址，按提示安装

管理器会自动弹出安装页。这是最新版地址，也是之后自动更新的来源：

https://regionnor.github.io/xue-xi-tong/chaoxing-ai-answer-assistant.user.js

也可以把仓库里的 chaoxing-ai-answer-assistant.user.js 拖进管理器，或复制内容新建脚本。

确认已启用并打开超星页面

安装后在管理器里确认脚本为启用状态。打开任意超星页面，右下角会出现一个蓝色圆形「AI」按钮，点击即可展开面板。

更新提示不出现时，可在管理器里手动点一次「检查更新」。脚本的 @updateURL 指向 GitHub Pages，缓存约 10 分钟。

配置 AI 接口（必做）

不配置 AI，脚本不会答题。

打开面板并切到「答题」

点击右下角「AI」按钮展开面板，选择顶部「答题」标签。

勾选「启用 AI 接口答题」

未勾选时不会调用 AI。

填写接口地址、密钥、模型

可先从下拉选择预设，自动填好接口地址；模型通常需要自己填写（如 gpt-4o-mini、deepseek-chat）。

点「测试连接」验证

脚本会发一个极简 ping 请求，成功会显示「连接成功（HTTP 200）」，失败会给出 HTTP 状态或网络 / 跨域原因。

刷新页面开始使用

配置会自动保存，下次打开无需重复填写。

面板会根据当前页面地址自动选择初始标签，避免停在无关页面；页面内跳转（不刷新）也会跟随更新。

常见问题

按「现象 → 原因 → 处理」整理。

点了「AI」按钮，面板打不开 / 没反应

先确认版本：1.22 存在一个渲染崩溃问题，会导致面板无法挂载，1.23 已修复。请在管理器里查看脚本版本，低于 1.23 请更新。

1.23 起，如果挂载仍然失败，页面左下角会出现一条红色错误提示条（约 8 秒），把上面的文字反馈即可定位。

另外请确认脚本为启用状态，且当前页面域名在「生效域名」范围内。

页面上出现了两个「AI」按钮，只有一个能用

这是 1.23 及更早版本的问题：脚本会注入到所有 *.chaoxing.com 的 iframe，每个 iframe 都创建了一个悬浮按钮，但只有顶层那个能打开全屏面板。

1.24 起已限制为只在顶层页面创建按钮与面板，更新后多余按钮会消失。

切换标签后，内容变了但顶部高亮没变

1.26 之前的问题：标签按钮的编译优化标记缺少 class 更新位，导致高亮不重算。

1.26 起已修复，点击哪个标签，高亮就跟着走。

我已经进了答题页，面板却还显示「首页」

1.25 起，面板会根据页面地址自动选择标签：studentstudy、dowork、/work、homework、exam、mooc-ans 等页面显示「答题」，其余显示「首页」。

如果你的答题页地址比较特殊、没有被规则覆盖，可以手动点「答题」，或把地址反馈给作者加入规则。

更新了新版本，但脚本还是旧版

先确认版本：面板「首页」的第一条日志会打印「脚本加载成功，正在解析网页（当前版本 vX.Y）」，也可在管理器里查看。

更新地址已从 jsDelivr 换成 GitHub Pages（缓存约 10 分钟）。若刚发布不久，等几分钟或在管理器里手动点「检查更新」；仍是旧版可重新打开安装地址覆盖安装。

注意：从旧版本（jsDelivr 更新通道）升级时，需要手动重装一次新地址，之后才会走 Pages 通道。

日志提示「该页面无任务，请进入章节或答题页面使用」

说明当前页面（如课程详情页）没有可执行的任务点。进入具体章节、作业或考试页面即可。

「测试连接」失败：请求出错 / 超时 / 返回异常
  • 接口地址需为 OpenAI 兼容的 /v1 基址，不要带 /chat/completions。
  • 确认 API Key 正确、未过期，且账户有额度。
  • 确认模型名与所填接口匹配（不同服务商模型名不同）。
  • 超时时间为 20 秒；网络不稳定或被墙时可能失败，可换网络重试。
  • 返回异常时，提示里会带 HTTP 状态码与响应片段，可据此判断是鉴权、模型不存在还是余额问题。
视频不加速 / 拖不动进度条

部分课程由教师关闭了拖动，脚本会自动回退为「最高倍速播放」；倍速上限由播放器开放程度决定，课程未开放更高倍速时只能到 2x 左右。

配置会丢吗？换浏览器还在吗？

配置会保存在脚本存储（以及同源的 localStorage）中，刷新、重开页面都会保留。换浏览器 / 换设备不会自动同步，需要重新填写。
